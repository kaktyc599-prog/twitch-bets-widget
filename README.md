# 🎲 OBS Bets Overlay — ставки на баллы канала (Splicer_IRL)

Виджет для OBS Studio: показывает активные ставки на баллы канала
(Twitch Predictions) в стиле «Вопрос» с двумя вариантами ответов —
**синий** и **красный**.

```
┌──────────────────────────────────────────────┐
│  ● СТАВКА                      осталось 1:23 │
│  Кто победит в сегодняшнем матче?            │
│  ┌────────────────────┐ ┌──────────────────┐ │
│  │ ● Вариант 1        │ │ ● Вариант 2      │ │
│  │ 12.4K (40%)        │ │ 18.7K (60%)      │ │
│  └────────────────────┘ └──────────────────┘ │
│  [═══════ СИНИЙ │ ████ КРАСНЫЙ ═════════]    │
└──────────────────────────────────────────────┘
```

## Возможности

- 📊 Баллы и проценты у каждого варианта
- ⏱ Таймер до закрытия приёма ставок
- 🔒 Состояние «Закрыто» / «Результат» / «Отмена»
- 🏆 Подсветка победившего варианта + баннер результата
- 🎛 Настройка через URL, прозрачный фон для OBS

## Установка (5 минут)

### 1. Зарегистрируй приложение Twitch

1. Открой [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) → «Register Your Application»
2. Название: любое (например `OBS Bets`), OAuth Redirect URLs: `http://localhost/stavki`, категория: Chat Bot
3. Создай и скопируй **Client ID**.

### 2. Получи access-токен

Проще всего — открой `get-token.html` (лежит рядом с индексом) и следуй шагам:
вставь Client ID → кнопка авторизации → войди под **аккаунтом стримера** →
скопируй `access_token` из адресной строки → склей готовый URL виджета.

Скоуп: `channel:read:predictions` (только чтение ставок).

### 3. Добавь в OBS

1. Источники → **Браузер** 
2. Ссылка (URL) — собранная на шаге 2, либо локальный файл + параметры в URL.
3. Ширина/высота: **900 × 280** (можешь поменять). Должен работать, галочка «Заново подключаться при появлении».

## Параметры URL

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `?token=…` | из localStorage | access-токен Twitch |
| `&client_id=…` | из localStorage | Client ID приложения |
| `&channel=Splicer_IRL` | Splicer_IRL | канал для мониторинга |
| `&scale=1.1` | 1 | масштаб карточки |
| `&after=60` | 60 | сек показа результата (0 = держать всегда) |
| `&idle=hide` | показ | полностью скрыть, если ставки нет |
| `&poll=3` | 3 | период опроса API в секундах |

### Пример

```
file:///C:/Users/kaktyc599/Desktop/Splicer_Irl/stavki/index.html?token=abc123xyz&scale=1.1
```

## Ограничения

- Это **не** официальный способ — используется публичное Helix API с опросом (по умолчанию ~3 сек). 
- Токен привязан к аккаунту стримера и действует ~60 дней (обнови при 401).
- OBS кеширует localStorage: если токен обновится, достаточно просто
  перезагрузить источник браузера.
